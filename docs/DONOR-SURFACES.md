# Masamune (AI harness + dev surface) — repo slug `tracendroid`, module `:app`, package `com.ai.assistance.operit` — donor surface inventory

> Generated by reverse-engineering the donor apps' real menu trees, then merging
> them. **9 donors, 125 distinct surfaces.**
>
> This is the build spec for the rebuild: every node below is a menu, setting, or
> feature that exists in a donor and must exist here — merged where two donors do
> the same thing, kept separate where they genuinely differ. A node that ships as
> a visible control which does nothing is worse than one not yet built, so an
> unbuilt node stays off the screen until its engine exists.
